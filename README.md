#   具备 OTA 升级功能的汽车控制器与仪表屏系统

基于 STM32 的汽车仪表中控屏系统，实现 CAN 通信、LVGL 图形界面显示与基于 CAN 网络的 OTA 远程升级功能。

---

##  项目简介

本项目基于 STM32 系列单片机，搭建了一套汽车控制器与仪表屏系统：
- 整车外围控制器（VCU）与仪表中控屏通过 CAN 总线通信，传输车辆数据报文；
- 仪表中控屏使用 LVGL 实现车载 UI 界面，驱动 LCD 屏幕实时显示车辆信息；
- 实现了基于 CAN 网络的 OTA 固件升级功能，通过 Bootloader 完成固件更新与跳转。

---

##  硬件架构

本项目采用多节点 CAN 总线架构：

| 节点 | 核心芯片 | 功能说明 |
| :--- | :--- | :--- |
| 整车控制器（VCU） | STM32F103C8T6 | 模拟车辆数据，发送 CAN 报文，作为数据源节点 |
| 仪表中控屏 | STM32F103ZET6 | 运行 LVGL 界面，接收并解析 CAN 数据，驱动 LCD 显示 |
| USB 升级器 | STM32F103C8T6 | 桥接 PC 端与 CAN 总线，实现 Ymodem 协议固件下发 |

通信链路：
- **数据传输**：VCU → CAN 收发器 → 仪表中控屏，实现车辆数据实时显示；
- **固件升级**：PC → USB 升级器（Ymodem）→ CAN 总线 → 仪表中控屏 Bootloader。

##  核心功能实现

### 1. STM32 Bootloader 与 OTA 升级
- 将仪表屏控制器的 Flash 划分为 **Bootloader 区**与 **APP 区**，实现固件分区管理；
- 基于 CAN 总线实现固件数据接收、校验与写入；
- 完成 Bootloader 到 APP 的安全跳转，支持升级失败回滚机制；
- 配合 USB 升级器，通过 Ymodem 协议从 PC 端下发固件，实现远程升级流程。

### 2. LVGL 仪表界面开发
- 将 LVGL 开源图形库移植到 STM32F103ZET6 平台；
- 实现 LCD 屏幕硬件 SPI 驱动，并对驱动代码进行 DMA/缓存优化，显著提升 LVGL 界面刷新率；
- 开发车辆仪表盘 UI，支持车速、转速、状态指示灯等信息的实时显示。

### 3. CAN 总线通信系统
- 实现多节点 CAN 网络通信，支持整车控制器与仪表屏之间的报文收发；
- 模拟实际汽车应用场景，VCU 发送车辆数据，仪表屏解析并显示；
- 支持调试模式下通过 PC 端串口模拟发送 CAN 报文，便于功能测试。

##  快速上手

### 硬件准备
- STM32F103ZET6 开发板（仪表中控屏节点）
- STM32F103C8T6 开发板 ×2（VCU + USB 升级器节点）
- CAN 收发器模块（如 TJA1050）×3
- SPI 接口 LCD 屏幕（如 2.4/3.2 寸 TFT）
- USB-TTL 模块（用于串口调试与升级）

### 编译与烧录
1.  **Bootloader 烧录**
    - 编译 `34Bootloader` 工程，生成 `.bin` 文件；
    - 使用 ST-Link 将 Bootloader 固件烧录到 STM32F103ZET6 的 Flash 起始地址；
2.  **APP 固件编译**
    - 编译 `32Car_APP` 工程，生成 `.bin` 文件，设置链接脚本偏移地址与 Bootloader 分区匹配；
3.  **OTA 升级测试**
    - 将 `31usb_tool` 固件烧录到 STM32F103C8T6，连接 PC 串口；
    - 按架构图连接 CAN 总线，通过 PC 端串口工具发送 APP 固件，触发 OTA 升级流程。
